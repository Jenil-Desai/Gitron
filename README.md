# 🚀 Gitron - Your Lightweight Gateway to GitHub on Desktop

**Gitron** is a sleek, cross-platform GitHub desktop client built with **Flutter**. Designed for simplicity and speed, Gitron enables developers to authenticate securely, fetch GitHub data efficiently, and enjoy a responsive native experience across Windows, macOS, and Linux.

> Flutter-powered. Developer-optimized.

## ⚙️ Setup

1. Clone the repository:
   ```bash
   git clone <repo_url>
   ```
2. Navigate to the project directory:
   ```bash
   cd gitron
   ```
3. Open the project in **VS Code** or **Android Studio**
4. Get dependencies:
   ```bash
   flutter pub get
   ```
5. Run the app:
   ```bash
   flutter run -d windows   # or macos / linux
   ```
